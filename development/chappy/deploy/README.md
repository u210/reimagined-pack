# Chappy production operations

- Host: SSH alias `kagoya-minecraft` only; Minecraft `/opt/reimagined`.
- Gateway code: `/opt/chappy/gateway`; pinned executables `/opt/chappy/node` (24.13.1), `/opt/chappy/codex` (0.144.1).
- Service: `chappy-gateway.service`, dedicated Unix user `chappy`, loopback port 18765.
- Model/auth: `gpt-5.6-luna`, `max`, ChatGPT device login. No API key.
- Private configuration: `/etc/chappy/gateway.env` (root, 0600) and `/opt/reimagined/config/chappy-common.toml` (minecraft, 0600).
- Private account/runtime: `/var/lib/chappy/codex-home`, owned by chappy, 0700. Never publish or include in client downloads.
- Knowledge: only `/opt/reimagined/chappy-knowledge.json`, regenerated by the running production Mod. No local test snapshot fallback.
- Player memory stays in the production world. Do not copy test worlds, photographs or player memory.

Node was downloaded from nodejs.org, fixed version 24.13.1, with its published SHA-256 verified. Codex was extracted from the official npm `@openai/codex@0.144.1-linux-x64` archive with registry SHA-512 integrity verified; no npm lifecycle scripts were run.

To renew authentication, run on the VPS:

```sh
runuser -u chappy -- env CODEX_HOME=/var/lib/chappy/codex-home /opt/chappy/codex login --device-auth
systemctl restart chappy-gateway.service
```

The service restarts the Gateway and native child together after failures, and limits their combined memory to 768 MiB. The port is not exposed publicly. `/health` confirms gateway availability, not successful inference: verify a real `/v1/ask` when testing authentication or models.

Deploy Minecraft through the guarded repository wrapper, preserving Sawmill, MPI reimagined-2, Xaero server restrictions, and Chunky state. The expected server Mod count for this release is 221. Do not distribute the private Chappy config: the public Mod defaults to an empty token.

Rollback after a failed startup restores the backed-up managed files automatically. Once players have used new Mod content, restoring a world snapshot is a separate decision that loses newer play; never perform it silently.

Chappy and Exposure are both required on clients. Packwiz updates install both, then clients must restart Minecraft. Administrator Prism additions are backed up and applied separately from the public pack.
